# 📝 Write-Ups

A collection of writeups for CTF machines and labs from platforms like TryHackMe, Hack The Box, and VulnHub.

These writeups are meant to be educational — each one walks through the methodology, tools, and thought process used to compromise the machine, with beginner-friendly explanations along the way.

---

## 🗂️ Structure

Each writeup lives in its own folder named after the machine:
```
write-ups/
├── Attacktive Directory/     ← TryHackMe
├── ...
```
